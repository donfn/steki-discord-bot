Το υλικό του Steki μέσα στο Claude και το ChatGPT

Σύνδεσε το Claude ή το ChatGPT με το υλικό των μαθημάτων και ζήτα τους να ψάξουν ή να διαβάσουν αρχεία. Συνδέεσαι με τον λογαριασμό σου στο Discord και η πρόσβαση είναι μόνο για ανάγνωση.

{{.URL}}

Πώς θα το συνδέσεις

  1. Άνοιξε το Claude (claude.ai ή την εφαρμογή) και πήγαινε Settings → Connectors.
  2. Πάτα Add custom connector.
  3. Στο όνομα γράψε Steki, στο URL επικόλλησε τη διεύθυνση από πάνω και πάτα Add.
  4. Πάτα Connect. Θα ανοίξει το Discord: συνδέσου και πάτα Επιτρέπω.
  5. Σε μια νέα συζήτηση ενεργοποίησε το connector Steki από το μενού εργαλείων και ρώτα ό,τι θέλεις.

Αν χρησιμοποιείς το Claude μέσω του οργανισμού σου, ίσως πρέπει να προσθέσει το connector ο διαχειριστής του.

  1. Πήγαινε Settings → Apps (στις παλιότερες εκδόσεις λέγεται Connectors) και άνοιξε τα Advanced settings.
  2. Ενεργοποίησε το Developer mode.
  3. Πάτα Create, γράψε όνομα Steki και στο MCP server URL επικόλλησε τη διεύθυνση από πάνω.
  4. Στο Authentication διάλεξε OAuth, αποδέξου την προειδοποίηση εμπιστοσύνης και πάτα Create.
  5. Πάτα Connect, συνδέσου στο Discord και πάτα Επιτρέπω.
  6. Σε νέα συζήτηση διάλεξε το Steki από το + → More (με ενεργό το Developer mode) και ρώτα ό,τι θέλεις.

Το Developer mode δεν υπάρχει σε όλα τα πλάνα και τα ονόματα των μενού αλλάζουν συχνά. Αν δεν βρίσκεις κάτι, ψάξε «connector» ή «MCP» στις ρυθμίσεις.

Ο server υποστηρίζει Streamable HTTP MCP με OAuth 2.1 (PKCE και dynamic client registration).

Claude Code:

claude mcp add --transport http steki {{.URL}}
  1. Μέσα στο Claude Code γράψε /mcp, διάλεξε steki και μετά Authenticate.
  2. Συνδέσου στο Discord και πάτα Επιτρέπω. Μετά ο browser σε γυρνάει στο τερματικό.

Για άλλους clients (Cursor, VS Code, MCP Inspector κ.ά.) πρόσθεσε remote server τύπου HTTP με αυτό το URL. Το metadata είναι στο /.well-known/oauth-authorization-server και τα δημόσια κλειδιά (JWKS) στο /.well-known/jwks.json.

Τι μπορεί να κάνει

list_course_channels

Τα κανάλια των μαθημάτων και πόσα αρχεία έχει το καθένα.

get_material_index

Τα αρχεία ενός καναλιού: όνομα, περιγραφή, ημερομηνία και ποιος τα ανέβασε.

download_material

Κατεβάζει ένα PDF ή μια φωτογραφία για να το διαβάσει το AI.

Δοκίμασε να ρωτήσεις

  • Για ποια μαθήματα υπάρχει υλικό;
  • Βρες τα θέματα εξετάσεων που έχουν ανέβει για τους Αλγορίθμους.
  • Διάβασε τις πιο πρόσφατες σημειώσεις του καναλιού και κάνε μια περίληψη.
  • Λύσε το Θέμα 2 από το πιο πρόσφατο αρχείο θεμάτων.

Τι πρέπει να ξέρεις

  • Μπορεί μόνο να διαβάζει. Δεν γράφει, δεν σβήνει και δεν στέλνει μηνύματα.
  • Βλέπει μόνο τα κανάλια που βλέπεις κι εσύ. Αν χάσεις τον ρόλο σου ή φύγεις από τον server, η πρόσβαση σταματά.
  • Η σύνδεση λήγει μετά από 30 ημέρες και τότε συνδέεσαι ξανά.
  • Από το Discord παίρνουμε μόνο το όνομά σου. Το bot δεν αποθηκεύει κωδικούς ή tokens του Discord.
  • Για να σταματήσεις την πρόσβαση, αφαίρεσε το connector από το Claude ή το ChatGPT.
