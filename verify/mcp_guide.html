Το υλικό του Steki, μέσα στο AI σου

Συνδέεις το Claude ή το ChatGPT με το υλικό των μαθημάτων και τους ζητάς να βρουν, να διαβάσουν και να συνοψίσουν σημειώσεις και θέματα. Μόνο ανάγνωση, με τον λογαριασμό σου στο Discord.

{{.URL}}

Οδηγίες σύνδεσης

  1. Άνοιξε το Claude (claude.ai ή την εφαρμογή) και πήγαινε στο Settings → Connectors.
  2. Πάτα Add custom connector.
  3. Στο όνομα γράψε Steki και στο URL επικόλλησε τη διεύθυνση από πάνω. Πάτα Add.
  4. Πάτα Connect. Ανοίγει το Discord: συνδέσου και πάτα Επιτρέπω.
  5. Σε μια νέα συνομιλία ενεργοποίησε το connector Steki από το μενού των εργαλείων και ρώτα ό,τι θέλεις.

Αν το Claude σου ανήκει σε οργανισμό, ίσως χρειαστεί να προσθέσει το connector ο διαχειριστής του. Αφού συνδεθείς στον υπολογιστή, το connector φαίνεται και στο κινητό.

  1. Στο ChatGPT πήγαινε στο Settings → Apps (σε παλιότερες εκδόσεις: Connectors) και άνοιξε τα Advanced settings.
  2. Ενεργοποίησε το Developer mode.
  3. Πάτα Create για νέα εφαρμογή, γράψε όνομα Steki και στο MCP server URL επικόλλησε τη διεύθυνση από πάνω.
  4. Στο Authentication διάλεξε OAuth, δέξου την προειδοποίηση εμπιστοσύνης και πάτα Create.
  5. Πάτα Connect, συνδέσου στο Discord και πάτα Επιτρέπω.
  6. Σε νέα συνομιλία διάλεξε το Steki από το + → More (με το Developer mode ενεργό) και ρώτα.

Το Developer mode υπάρχει σε επιλεγμένα πλάνα του ChatGPT και τα ονόματα στα μενού αλλάζουν συχνά. Αν δεν βρίσκεις μια επιλογή, ψάξε για «custom connector» ή «MCP» στις ρυθμίσεις.

Ο server μιλάει Streamable HTTP MCP με OAuth 2.1 (PKCE και dynamic client registration), άρα δουλεύει με κάθε σύγχρονο MCP client.

Claude Code

claude mcp add --transport http steki {{.URL}}
  1. Μέσα στο Claude Code γράψε /mcp, διάλεξε steki και Authenticate.
  2. Συνδέσου στο Discord και πάτα Επιτρέπω. Ο browser γυρίζει στο τερματικό.

Άλλοι clients (Cursor, VS Code, MCP Inspector κ.ά.): πρόσθεσε έναν remote server τύπου HTTP με αυτό το URL. Το metadata βρίσκεται στο /.well-known/oauth-authorization-server και τα δημόσια κλειδιά (JWKS) στο /.well-known/jwks.json.

Τι μπορεί να κάνει

list_course_channels

Βρίσκει τα κανάλια των μαθημάτων, με πόσα αρχεία έχει το καθένα.

get_material_index

Δείχνει όλο το υλικό ενός καναλιού: ονόματα, περιγραφές, ημερομηνίες, ποιος το ανέβασε.

download_material

Κατεβάζει ένα PDF ή μια φωτογραφία, ώστε το AI να τη διαβάσει.

Δοκίμασε να ρωτήσεις

  • Τι μαθήματα έχουν υλικό στο Steki;
  • Βρες τα θέματα εξετάσεων που έχουν ανέβει για το μάθημα Αλγόριθμοι.
  • Διάβασε τις πιο πρόσφατες σημειώσεις του καναλιού και φτιάξε μου περίληψη.
  • Λύσε το Θέμα 2 από το πιο πρόσφατο αρχείο θεμάτων.

Ασφάλεια και ιδιωτικότητα

  • Μόνο ανάγνωση. Δεν μπορεί να γράψει, να διαγράψει ή να στείλει μηνύματα.
  • Βλέπει ό,τι βλέπεις. Μόνο τα κανάλια που έχεις πρόσβαση στο Discord, και μόνο όσο είσαι ολοκληρωμένο μέλος του server.
  • Λήγει σε 30 ημέρες. Μετά συνδέεσαι ξανά με ένα κλικ.
  • Το Discord δίνει μόνο το όνομά σου. Το bot δεν κρατά κωδικούς ούτε tokens του Discord.
  • Ανάκληση. Αφαίρεσε το connector από τις ρυθμίσεις του Claude ή του ChatGPT, ή βγες από τον server.

Αυτή η σελίδα ανανεώνεται μέσω του κουμπιού στο μήνυμα του Steki.
